# ARIA | Inteligência Regulatória com IA Generativa 🚀

🥈 **2º Lugar Geral** no **Hackathon Talento Tech 3.0 – Escola da Nuvem – Hacking for Good 2026**

**Solução:** _Extração de Conhecimento em Dados Complexos_

A **ARIA** é uma plataforma de Inteligência Regulatória com IA Generativa criada para automatizar a leitura, interpretação e o monitoramento contínuo de documentos técnicos, científicos e regulatórios, com foco em conformidade, rastreabilidade e agilidade na tomada de decisão.

## Slide 5 — Arquitetura da Solução

![Slide 5 - Arquitetura ARIA](https://www.genspark.ai/api/files/s/6ApfBnTk)

A arquitetura da ARIA foi desenhada em modelo **cloud native e serverless**, com dois fluxos principais: **manual** e **automático**. No fluxo manual, o usuário acessa a aplicação, envia documentos e consulta o sistema. No fluxo automático, rotinas programadas coletam conteúdos externos, processam dados e atualizam a base de conhecimento continuamente.

Principais componentes identificados na arquitetura:

- **Amazon S3** para armazenamento
- **AWS Lambda** para processamento serverless
- **Amazon API Gateway** para chat e upload
- **AWS Step Functions** para orquestração
- **Amazon SQS** para resiliência
- **Amazon Textract** para extração textual
- **Amazon Bedrock** para IA generativa
- **Knowledge Bases** e **OpenSearch Serverless** para busca semântica
- **Amazon EventBridge** para automação
- **Parameter Store** para prompts e parâmetros
- **Amazon CloudWatch** para observabilidade
